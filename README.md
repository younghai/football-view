# FootballView

**티켓을 사기 전에, 실제로 그 자리에 앉았을 때 보이는 풍경을 미리 보는 인터랙티브 3D 축구장 좌석 뷰어.**

프로시저럴(절차 생성) 3D 경기장을 자유롭게 탐색하고, 34,000+ 좌석 중 하나를 클릭하면
카메라가 그 좌석으로 날아가 1인칭 관중 시점을 보여줍니다. 좌석 등급·가격(€/$ 병기)·
시야 점수·혜택을 확인하고, 데모 결제(체크아웃 → QR 티켓)까지 진행할 수 있습니다.

> ⚠️ 컨셉 데모입니다. 경기·가격·좌석 가용성·결제는 모두 시뮬레이션이며 실제 티켓이 판매되지 않습니다.

---

## 설치 및 실행

**요구 사항**: Node.js 20.19+ (권장 22+), npm

```bash
git clone <this-repo-url> football-view
cd football-view
npm install

npm run dev      # Vite 개발 서버 → http://localhost:5173
npm run build    # 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 로컬 미리보기
npm test         # 좌석 가격/시야점수 로직 유닛 테스트 (node:test)
```

## 주요 기능

### 3D 경기장 (완전 프로시저럴 — 임포트 모델 0)
- 105×68m 잔디(모잉 스트라이프 + 규격 라인마킹), 골포스트+네트, 코너 플래그
- 3단 관중석(Lower / Club / Upper, 34,526석), 지붕 캐노피, 외벽, 플러드라이트 파일런
- 실시간 스코어+경기시계 전광판, 스크롤 LED 페리미터 보드
- IBL 환경광 + Bloom 포스트 프로세싱, 시간대 프리셋(야간/노을/낮) — 조명·하늘·안개·노출 전환
- 성능에 따라 픽셀비/블룸을 자동 조절하는 적응형 품질(high/medium/low)

### 좌석 & 구매 플로우
- 34,526개 개별 선택 좌석을 `InstancedMesh` 1드로우콜로 렌더링, 섹션별 팔레트, 팔린 좌석 표시
- 좌석 클릭 → GSAP 카메라 플라이트 → 눈높이 1인칭 시점(드래그 룩어라운드, 휠 시야 줌)
- 좌석 카드: 섹션/블록/열/좌석, **€/$ 병기 가격**, 시야 점수(★%), 등급별 혜택, 실렌더 POV 썸네일 + 인접 좌석 팬포토 2컷
- 검색/필터: 가격대 슬라이더 + 등급 + "Best view"(조건 내 최고 시야 추천 & 하이라이트)
- Stadium Overview 맵에서 섹션 직접 클릭 → 해당 섹션 좌석 진입
- **체크아웃 모달**: 주문 요약(수수료 포함 총액, €/$ 병기) → 데모 결제 폼 → 처리 애니메이션 → 좌석별 시드 QR 티켓

### 생동감 & 부가 기능
- 캔버스 아틀라스 빌보드 관중(1드로우콜) + **골 세리브레이션 웨이브**(전광판 득점과 연동)
- 포메이션을 도는 선수 22명 + 심판 + 굴러가는 공
- 합성 관중 음향(WebAudio, 오디오 에셋 0바이트)
- 2D 탑뷰, 사이드바이사이드 스테레오 뷰, 라이브 미니맵
- 즐겨찾기(localStorage), `prefers-reduced-motion` 대응, aria-live 스크린리더 안내, WebGL 미지원 폴백 화면
- 분석 이벤트 로거(`app_open`, `seat_preview`, `filter_apply`, `best_pick`, `section_pick`, `goal_celebration`)

```
football-view/

├── public/
│   └── favicon.svg

│   └── seat-logic.test.mjs # 가격·시야점수 순수 함수 유닛 테스트

    ├── main.js             # 부팅, 플로우 연결, 렌더 루프, 통합 와이어링
    ├── config.js           # 경기장 치수·티어·요금·팔레트·데모 경기 데이터
    ├── scene.js            # 렌더러/카메라/조명/하늘돔/IBL/시간대 프리셋

    ├── pitch.js            # 잔디 텍스처, 라인, 골포스트, 코너 플래그

    ├── seats.js            # 좌석 생성 + 인스턴싱 + 하이라이트 배치 API
    ├── seat-logic.js       # 가격/시야점수 순수 함수 (의존성 없음, 테스트 대상)
    ├── search.js           # 좌석 검색/필터/베스트뷰 UI 로직
    ├── actors.js           # 빌보드 관중(+세리브레이션 웨이브), 선수/공/심판
    ├── cameraRig.js        # 궤도 컨트롤, GSAP 플라이트, 좌석 룩어라운드
    ├── minimap.js          # 라이브 미니맵 + 클릭 가능한 오버뷰 섹션 맵
    ├── picker.js           # 좌석 레이캐스트 호버/선택 + 툴팁
    ├── audio.js            # 합성 관중 음향
    ├── analytics.js        # 경량 이벤트 로거
    ├── ui.js               # 좌석 카드/POV·팬포토 캡처/체크아웃 모달/토스트
    ├── util.js             # 공용 헬퍼 (즐겨찾기 키, €→$ 환산)
    └── style.css           # 전체 UI 스타일 (디자인 토큰은 :root 변수)
```

## 기술 스택

- [Three.js](https://threejs.org/) `0.180` — WebGL 렌더링, InstancedMesh, EffectComposer/Bloom, 커스텀 셰이더
- [GSAP](https://gsap.com/) `3.12.5` — 카메라 플라이트/트윈, 렌더 루프 티커
- [Vite](https://vite.dev/) `7` — 개발 서버/번들러
- 테스트: Node 내장 `node:test` (추가 프레임워크 없음)
